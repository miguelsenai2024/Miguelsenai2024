## Sobre

Construo aplicações web completas, do banco de dados à interface, com foco em **backend, integração de serviços e automação de processos**. Uso inteligência artificial como ferramenta prática: para reduzir trabalho manual, acelerar o acesso à informação e entregar produtos que resolvem problemas reais.

- **Atuação:** desenvolvimento web, APIs REST, modelagem de dados e automações
- **Explorando:** arquitetura de sistemas, IA generativa e cloud (AWS Cloud Foundations)
- **Em construção:** PersonalHub, GSPlan e Vyzor
